# OpenAgentSec Research Artifact Index

---

## 1. Overview

The `artifact/` directory contains the complete, canonical, machine-readable release artifacts of OpenAgentSec v1.0.0. All artifacts are strictly versioned, JSON Schema-validated, and cryptographically verified via `artifact/MANIFEST.json`.

```text
artifact/
├── MANIFEST.json                  # Top-level checksum manifest & metadata
├── benchmark/                     # Benchmark definitions and registries
│   ├── benchmark_v1.0.0.json      # Unified Benchmark Suite export
│   ├── scenarios.json             # 15 Canonical Benchmark Scenarios
│   ├── metrics.json               # 29 Formal Security & Operational Metrics
│   ├── targets.json               # 9 Cataloged Target Profiles
│   └── adaptive_scenarios.json    # Phase 12 Adaptive Attack Discovery Variants
├── experiments/                   # Empirical evaluation results & matrices
│   ├── reproduction_matrix.json   # 5-Run Zero-Variance statutory reproduction data
│   └── benchmark_results.json     # Quantitative results across all targets
└── schemas/                       # JSON Schemas enforcing contract integrity
    ├── target_profile.schema.json # TargetProfile schema
    ├── evidence.schema.json       # EvidenceItem & EvidenceContract schema
    ├── result.schema.json         # BenchmarkResult & OracleResult schema
    └── mutation.schema.json       # AttackTrace & MutationScenario schema
```

---

## 2. Artifact Catalog Details

### 2.1 Benchmark Registries (`artifact/benchmark/`)

| File Name | Description | Provenance / Generation Source | Usage |
|---|---|---|---|
| `benchmark_v1.0.0.json` | Comprehensive release package containing all scenarios, targets, policies, objectives, and metric declarations. | Generated by `scripts/generate_research_artifacts.py` via `BenchmarkRegistry.to_dict()`. | Primary distribution file for third-party benchmark runners. |
| `scenarios.json` | Catalog of 15 canonical benchmark scenarios spanning Memory Poisoning, RAG Injection, Authorization Bypass, and Trust Networks. | Exported from `src/openagentsec/benchmark/scenario_registry.py`. | Used for scenario indexing and selective evaluation execution. |
| `metrics.json` | Definitions of 29 canonical metrics across Violation, Observability, Reproduction, Trajectory, Multi-Agent, Governance, and Adaptive domains. | Exported from `src/openagentsec/benchmark/metric_registry.py`. | Standardized scorecard generation and cross-target comparison. |
| `targets.json` | Declarations of 9 standard Target Profiles (LangGraph, LangChain, MCP Gateway, OpenAI API, DeepSeek API, Multi-Agent, etc.). | Exported from `src/openagentsec/benchmark/target_catalog.py`. | Configures runtime adapter capability bounds and isolation requirements. |
| `adaptive_scenarios.json` | 4-Dimensional mutation variants generated by the Phase 12 Adaptive Attack Discovery engine. | Exported from `src/openagentsec/adaptive/attack_generator.py`. | Continuous red-teaming and automated exploit discovery. |

---

### 2.2 Empirical Experiment Data (`artifact/experiments/`)

| File Name | Description | Provenance / Generation Source | Usage |
|---|---|---|---|
| `reproduction_matrix.json` | Quantitative multi-run matrix validating 100% statutory 5-run zero-variance across all canonical targets. | Aggregated by `ReproductionAggregator` across test runs. | Validates scientific reproducibility claim ($\text{Variance} = 0.0000$). |
| `benchmark_results.json` | Reference evaluation results for all cataloged targets under safe vs vulnerable configurations. | Compiled from execution runs in `tests/integration/`. | Baseline reference for external researchers comparing new agent defenses. |

---

### 2.3 Formal JSON Schemas (`artifact/schemas/`)

| File Name | Target Object Schema | Validated Structure |
|---|---|---|
| `target_profile.schema.json` | `TargetProfile` | Validates target ID, type, isolation tier, observability states, and sandbox bounds. |
| `evidence.schema.json` | `EvidenceItem` | Validates evidence ID, 13 canonical types, cryptographic signatures, provenance, and verification flags. |
| `result.schema.json` | `OracleResult` & `ReproductionSummary` | Validates deterministic decisions, reason codes, baseline hashes, and 5-run consensus fields. |
| `mutation.schema.json` | `AttackTrace` & `MutationScenario` | Validates 4-D mutation dimensions, step records, parent trace IDs, and causal attribution tags. |

---

## 3. How to Regenerate Artifacts

All research artifacts can be re-exported deterministically from the codebase:

```bash
# 1. Regenerate all JSON artifacts and schemas
python3 scripts/generate_research_artifacts.py

# 2. Verify all artifacts against the test suite and MANIFEST.json
bash scripts/verify_release.sh
```
