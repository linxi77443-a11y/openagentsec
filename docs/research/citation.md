# Citing OpenAgentSec

If you use OpenAgentSec in your academic research, industrial evaluation, or security benchmarking, please cite the framework using the following references:

---

## 1. BibTeX Format

```bibtex
@software{OpenAgentSec2026,
  author       = {OpenAgentSec Contributors},
  title        = {{OpenAgentSec: A Research Framework for Evidence-based Security Evaluation of Tool-Using AI Agents}},
  year         = {2026},
  version      = {1.0.0},
  publisher    = {GitHub},
  url          = {https://github.com/linxi77443-a11y/openagentsec},
  license      = {Apache-2.0}
}
```

---

## 2. APA Format

```text
OpenAgentSec Contributors. (2026). OpenAgentSec: A Research Framework for Evidence-based Security Evaluation of Tool-Using AI Agents (Version 1.0.0) [Computer software]. https://github.com/linxi77443-a11y/openagentsec
```

---

## 3. Markdown Reference

```markdown
[OpenAgentSec](https://github.com/linxi77443-a11y/openagentsec) (v1.0.0): A Research Framework for Evidence-based Security Evaluation of Tool-Using AI Agents.
```
