## 硬规则

**主线通道规则**：主线任务必须穿过至少 4 个平台层：

```
风险对象 → 验证方法 → 证据输出 → 整改 / 复测
```

只补 validator / fixture / parser / matrix / scorecard 的任务默认是辅助工程，不能作为主线。

**否决规则**：

- 说不清对应企业风险 → 不进入开发
- 说不清验证证据 → 不进入开发
- 只能输出 validation passed → 不作为主线
- 辅助工程必须绑定到明确风险验证任务，否则不做

## 辅助工程判定

以下类型的任务默认是辅助工程，不能作为主线进展：

- validator / fixture / parser 新增或修改
- matrix schema / mapping 对齐
- scorecard schema 调整
- runner 框架扩展（不含新风险验证）
- YAML 结构整理
