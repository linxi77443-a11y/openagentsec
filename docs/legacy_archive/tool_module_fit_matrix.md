## 工具说明

| 工具 | 说明 |
|---|---|
| **promptfoo** | 自动化红队测试框架，支持断言、回归、多 provider。用于执行测试用例并验证输出是否符合预期 |
| **garak** | 对抗性测试框架，补充 promptfoo 未覆盖的测试模式 |
| **DeepSeek judge** | AI-assisted 结果评审工具，用于评估 finding 严重度和误报率 |
| **PII detector** | 敏感数据检测器，用于验证输出中是否包含 PII/凭据 |
| **retrieval trace** | RAG 检索链路追踪工具，用于验证检索结果和权限过滤 |
| **local rules / assertions** | 本地规则引擎和断言逻辑，用于输出验证和信号检测 |
| **authorized test API** | 已授权的测试目标 API，用于执行真实 API 测试 |
| **local sandbox** | 本地沙箱环境，用于在隔离环境中执行测试 |
| **mock Agent tools** | 模拟 Agent 工具调用，用于验证 Agent 行为安全 |
| **tool-call logger** | 工具调用日志记录器，用于审计 Agent 行为 |
| **code sandbox inspector** | 代码执行沙箱检查器，用于验证沙箱隔离效果 |

## 适配原则

1. **每个模块至少有一个核心工具**（●）。没有核心工具的模块不应进入验证阶段。
2. **DeepSeek judge 作为通用评审工具**覆盖所有模块，但不替代各模块的专用验证工具。
3. **local sandbox 是默认执行环境**，authorized test API 仅在需要真实 API 验证时使用。
4. **P0 模块优先使用已有工具链**（promptfoo + DeepSeek judge + local rules），减少工具链新增。
5. **P2 模块在投入前需重新评估工具适配性**，当前矩阵可能不充分。
