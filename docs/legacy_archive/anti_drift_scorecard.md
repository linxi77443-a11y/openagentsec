# 漂移评分规则

## 评分项

| 分值 | 条件 |
|------|------|
| +1 | 任务名称主要是 validator / fixture / parser / matrix / scorecard |
| +1 | 说不清对应哪个企业 AI / Agent 风险 |
| +1 | 说不清验证对象 |
| +1 | 说不清输出证据 |
| +1 | 输出主要是 YAML / passed count，而不是 finding / evidence / remediation |
| +1 | 任务来自已有代码惯性，而不是风险矩阵或企业场景 |
| +1 | 新增多个流程文件，但没有新增风险验证或证据输出能力 |
| +1 | Claude Code 自行推导下一阶段，而不是用户确认 |

## 判断

| 总分 | 结论 |
|------|------|
| 0–1 | 可以进入开发 |
| 2 | 只能作为小补丁 |
| >=3 | 暂停，重新对齐 |
