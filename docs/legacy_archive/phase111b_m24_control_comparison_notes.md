# Phase 111B M24 Control Effectiveness Comparison

## Methodology

This module compares different security control configurations (e.g., strict, standard, lenient) against a baseline. The comparison is entirely synthetic using `<SIM_...>` placeholders.

## Metrics
- **Interception Rate Increment**: Increase in interception rate compared to baseline.
- **Benign Usability Loss**: Decrease in benign usability compared to baseline.
- **False Positive Increment**: Increase in false positive rate compared to baseline.

## Findings
All findings are candidate and require human review. The metrics are generated synthetically.
