## 1. 项目概述

本项目是面向企业授权场景的 AI/Agent 攻击矩阵覆盖与行为能力评估平台。通过模拟攻击者视角，系统性验证 AI/Agent 在安全边界内的行为能力。

**核心定位**: 不是漏洞扫描器，不是真实攻击平台，不是生产安全声明工具。严格限定为合成评估场景。
