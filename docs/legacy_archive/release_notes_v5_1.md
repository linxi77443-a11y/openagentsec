# v5.1 Release Notes

## 英文总结 (English Summary)
Welcome to Enterprise AI Security Platform v5.1! This major release solidifies the platform's foundation and introduces critical capabilities:
- **Reproducible Test Environment**: Complete transition to modern Python packaging (`pyproject.toml`).
- **Engine V2 Layered Architecture**: Introduction of Converter, Orchestrator, Scorer, and Memory components.
- **ATLAS v5.4 Support**: Full mapping of MITRE ATLAS v5.4 and OWASP 2026.
- **Advanced Modules**:
  - M24 Control Effectiveness Comparison
  - M25 Security Rule Calibration
  - Adaptive Attack Simulation
  - Canary Token Data Leak Judgment
- **Traceable Reporting**: Enhanced reporting mechanism ensuring strict reproducibility and accountability.

欢迎使用企业级 AI 安全评估平台 v5.1！本次重大更新巩固了平台底座，并引入了多项关键能力：
- **可复现的测试环境**：全面迁移至现代 Python 打包规范 (`pyproject.toml`)。

- **高级评估模块**：
  - M24 控制有效性对比模块
  - M25 安全规则校准模块

  - 基于金丝雀令牌的数据外发研判
- **可追溯报告**：增强的报告机制，确保严格的可复现性与问责溯源能力。
